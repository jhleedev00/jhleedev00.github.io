STM32 기반 실시간 온도 제어 시스템

목표 온도에 따라 히터와 환풍구를 제어하는 식품 건조용 펌웨어입니다. 온도 센서, 사용자 입력, 표시 장치를 연결하고 팬 구동 드라이버를 구성했습니다.

STM32F103C8T6 / F407 C STM32 HAL DS18B20 (One-Wire) SPI FND I2C OLED UART RS-232

▸ 목표 온도 설정 및 측정

버튼과 토글 스위치로 목표 온도를 설정하고(UP/DOWN → FIX), DS18B20 디지털 온도 센서로 챔버 내부 온도를 실시간 측정했습니다.

▸ 조건에 따른 구동 상태 전환

▸ 주변장치 통합 및 확인 범위

OLED와 SPI 방식 FND로 온도를 표시했습니다. README에는 팬 자동 연동이 소개되어 있으나 실제 코드의 heaterControl 내 팬 호출은 주석 처리되어 있어, 히터·서보 제어와 팬 드라이버 구현까지를 확인 범위로 삼았습니다.
