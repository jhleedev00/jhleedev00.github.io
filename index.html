PROJECT 01 / LOGITLE02 — 02

IMPLEMENTATION / 정합에서 제어까지

정합 결과를
로봇의 움직임으로

LiDAR 점군을 목표 형상에 맞춘 뒤, 횡방향 오차와 방향 오차를 함께 반영해 도킹 중앙으로 접근합니다.

01 · 형상 기반 위치 추정

후방 시야와 ROI로 점군을 제한하고 cKDTree 최근접 대응점과 SVD로 2D 변환을 계산합니다. 이전 변환을 다음 정합의 초기값으로 사용합니다.

02 · 중앙 정렬과 저속 접근

횡방향 오차로 보정각을 계산합니다. 헤딩 오차가 15°를 넘으면 회전 정렬을 우선하고, 근접 구간에서는 후진 속도를 낮춥니다.

03 · 실패·취소 처리

매칭점이 10개 미만이면 정지합니다. 6회 연속 실패 시 초기 변환으로 재탐색하고, 취소 요청에는 정지 명령과 취소 결과를 반환합니다.

  1. 01
    LaserScan → 후방 ROI

    유효 거리·시야각 필터링

  2. 02
    V-Funnel → 2D ICP

    기준 형상과 측정 점군 정합

  3. 03
    상대 위치 → PID

    횡오차 보정 + 속도 제한

  4. 04
    TwistStamped → /cmd_vel

    정렬 / 후진 / 정지

일반 완료 분기의 판정 기준

거리 오차 < 0.06 m
횡방향 오차 < 0.015 m
ICP fitness > 0.4

위 값은 코드의 판정 조건이며 실측 정확도가 아닙니다. 근접 정지·사각지대에는 별도 완료 분기가 있어, 반복 도킹과 센서 유실 조건의 현장 검증이 필요합니다.

표시와 입력

OLED와 SPI 방식 FND로 온도를 표시하고, 버튼과 토글 스위치로 설정·운전을 제어합니다.
