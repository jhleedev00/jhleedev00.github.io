KICK-CAN - CAN 기반 분산 제어 4WD RC카

1

UART 수신 상태 머신·FDCAN 처리

  • 0xAA 탐색 → 12바이트 조립 → 0xFF·XOR 검증 상태 머신 구현
  • UART 데이터 밀림 대응: DMA → 인터럽트 수신 전환·정상 수신 확인
  • 수신 인터럽트 원형 큐 적재·메인 루프 CAN 메시지 분리 처리
2

차동 구동·CAN 하드웨어 디버깅

  • 좌우 차동 PWM 구동·장애물 방향별 출력 제한·ADC 전압 계측
  • 간헐 CAN 오류 시 오실로스코프 파형·연결 상태 계측 확인

3

휠 엔코더 펄스 노이즈 제외·무신호 타임아웃 처리

  • 낮은 펄스 빈도·복잡도 고려, TIM2 Input Capture IRQ 채택
