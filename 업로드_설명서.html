이정훈 포트폴리오 수정 및 배포 안내

HTML·CSS·JavaScript 기반의 정적 사이트입니다. 빌드 도구 없이 사용할 수 있습니다. 공개 사이트 주소는 https://jhleedev00.github.io/입니다. 로컬에서 수정한 내용은 GitHub에 반영하고 Pages 배포가 완료되어야 공개 사이트에도 표시됩니다.

로컬에서 확인하기

폴더 전체를 유지한 채 index.html을 Chrome 또는 Edge로 엽니다. 본문과 로컬 이미지는 인터넷 없이도 볼 수 있습니다. YouTube 영상, 외부 배지·이미지, GitHub 링크는 인터넷 연결이 필요합니다.

  • 상단 메뉴와 프로젝트 바로가기로 원하는 항목에 이동합니다.
  • 우측 하단 맨 위 ↑ 버튼으로 페이지 처음에 돌아갑니다.
  • 정밀 도킹 다이어그램은 Mermaid에서 생성한 로컬 SVG입니다. 작은 화면에서는 좌우로 넘겨 볼 수 있습니다.

A4 PDF 저장

상단 PDF 저장 / 인쇄 버튼을 누르고 용지를 A4 세로로 설정합니다. 배율 100%, 머리글·바닥글 끄기, 배경 그래픽 켜기를 권장합니다. 현재 페이지가 아니라 전체 포트폴리오를 출력하며, 페이지 수는 내용과 브라우저 설정에 따라 달라집니다.

YouTube 영상은 인쇄 시 클릭 가능한 썸네일로 대체됩니다. 썸네일이 로드된 뒤 출력하세요. 다이어그램은 벡터 이미지로 출력됩니다.

GitHub Pages에 반영하기

  1. 기존 jhleedev00.github.io 저장소에 수정한 파일을 반영합니다. 새 저장소를 만들 필요는 없습니다.
  2. 사이트 파일과 assets/, documents/의 연결 구조를 유지합니다. 테스트 산출물이나 원본 대용량 자료는 올리지 않습니다.
  3. 저장소의 Settings → Pages에서 현재 배포 설정을 확인합니다. 브랜치 방식이라면 main / (root)를 사용합니다.
  4. 배포 완료 후 공개 사이트를 새로고침해 변경 내용을 확인합니다.

내용과 미디어 수정

  • index.html: 본문, 프로젝트 설명, 사진 경로, YouTube 임베드 주소
  • styles.css: PC·모바일 및 인쇄 레이아웃
  • app.js: 메뉴 활성 상태, 썸네일 로딩 및 인쇄 처리
  • 정밀 도킹 흐름도 Figma 원본: 단계·아이콘·연결선·텍스트를 편집할 수 있습니다.
  • assets/docking-flow-figma.svg: 웹과 PDF에서 사용하는 Figma 디자인. 원본 수정 후 텍스트를 윤곽선으로 변환한 SVG로 내보내 교체합니다.

현재 프로젝트 순서는 LOGITLE, VIP Wearable, KICK-CAN, Guide Dog, Balancing Robot, PLC입니다. LOGITLE은 진행 중이며, 코드 설정·완료 판정 기준을 실측 정확도와 구분합니다. 팀 시스템 전체 기능과 개인 담당 업무도 구분해 작성합니다.

문제가 있을 때

  • 404: 배포 완료 여부와 저장소 최상위의 index.html을 확인합니다.
  • 사진이 표시되지 않음: 상대 경로, 파일명 대소문자, 업로드 누락을 확인합니다.
  • 이전 화면이 표시됨: 강력 새로고침(Ctrl+Shift+R)을 합니다.
  • YouTube 임베드 오류: 인터넷 연결과 영상의 임베드 허용 여부를 확인하고, 필요하면 영상 링크로 직접 엽니다.
